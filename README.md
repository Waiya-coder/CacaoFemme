# Cacao Femme

Marketing site for **Cacao Femme** — bean-to-bar chocolate grown by women, crafted by women, made for women.

## Stack

- [Vite](https://vitejs.dev/) + React + TypeScript
- [Tailwind CSS v4](https://tailwindcss.com/)

## Development

```bash
npm install
npm run dev
```

Open the URL shown in the terminal (typically `http://localhost:5173`).

## Build

```bash
npm run build
npm run preview
```

## Notes

- Photography uses Unsplash placeholders; replace with brand assets (Kenyan farmers, farm, product pack shots).
- Waitlist form is client-side only; wire to your email provider or API when ready.
- Contact email `hello@cacaofemme.com` is a placeholder.
